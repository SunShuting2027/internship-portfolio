# internship-portfolio

SQL / Python / Excel 数据分析实习作品集

一个从零搭建的数据分析练习仓库：记录工具学习、练习代码与三个可复现的分析项目。每个项目都按「业务问题 → 数据 → 方法 → 结论 → 复现步骤」组织。

## 技能栈

| 工具 | 当前状态 | 目标 |
| --- | --- | --- |
| Excel | 透视表、IF / COUNTIF / SUMIF / VLOOKUP、图表基础 | Power Query、动态看板 |
| SQL | SELECT / JOIN / GROUP BY 练习中 | 窗口函数、CTE、漏斗与留存 |
| Python | 基础语法入门 | pandas 清洗、matplotlib / seaborn 可视化 |
| 统计 | 数学专业背景 | 假设检验、A/B 测试、显著性判断 |

## 项目

### 01 · 电商销售复盘 `进行中`

- 业务问题：哪些品类 / 地区的销售在下滑，原因是什么
- 数据：公开电商订单数据集
- 方法：SQL 建表与指标计算（GMV / 订单数 / 客单价 / 退款率）→ pandas 交叉验证 → Excel 看板
- 产出：经营看板 + 3 条业务建议
- 复现：见 `project-01/README.md`

### 02 · 留存漏斗与假设检验 `待开始`

- 业务问题：注册到下单的漏斗在哪一步流失最大，改版是否真的有效
- 数据：用户行为日志
- 方法：SQL 窗口函数计算次日 / 7 日留存 → pandas cohort 热力图 → 卡方 / t 检验验证差异
- 产出：留存分析报告 + 显著性结论
- 复现：见 `project-02/README.md`

### 03 · 自动化周报 `待开始`

- 业务问题：如何把多张手工报表合并成一个可重复运行的流程
- 数据：多张结构不同的 Excel 源表
- 方法：pandas 批量读取与清洗 → 指标计算 → 格式化 Excel 输出 → Power BI 看板
- 产出：一键运行脚本 + 异常日志
- 复现：见 `project-03/README.md`

4. 第 10 周：简历、面试题库与岗位投递
